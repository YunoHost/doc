Since setting up a server at home is an uncommon practice, most Internet connections provided to individuals are unsuitable for this purpose especially if you desire to send mail. A net neutral VPN providing a dedicated fixed public IPv4 address and IPv6 addresses [can help to circumvent some limitations or difficulties](/admin/get_started/providers/vpn/vpn_advantage).

:::info
Note that except if you have a <a href="https://en.wikipedia.org/wiki/Threat_model">threat model</a> that implies to really be "hidden", you do not need to hide your home IP address using a VPN. It is really not a huge deal to expose your IP address, do not trust the big commercial VPN companies who tries to sell you a product by inducing fear.
If you *do* have such a threat model, especially against state threats, most of the providers listed below will **not** be of any help to you, since they will have to comply with police and judicial demands.
However, a VPN can help you to bypass port-forwarding limitations, or to get a stable IP address (if you ISP only provide dynamic IP) and this page will help you for that!
:::

Below, you can find a list of providers compatible for self-hosting and especially those providing .cube format for VPNClient apps and those providing [internetcube](https://internetcu.be).

:::info
By **compatible for self-hosting** we means VPN offers with at least:
- a fixed dedicated public IPv4
- port forwarding or opened features
- net neutrality: no traffic analysis, no user data resale, no alteration of traffic (without legal obligations)...
:::

:::info
Self-hosting notes, checked November 2026. VPNClient connects via OpenVPN (.ovpn import), so the IPv6 column reflects the provider's OpenVPN tunnel: Proton, IVPN and Windscribe only provide IPv6 over WireGuard (their .ovpn configs are IPv4-only, and Proton has marked OpenVPN Deprecated overall); PIA's client blocks IPv6 by design; AirVPN tunnels IPv6 natively inside OpenVPN. Mullvad removed OpenVPN on 2026-01-15, which is why VPNClient cannot use it. Fixed dedicated IPv4 exists only as a paid add-on for PIA (dedicated IP) and Windscribe (Static IP, 2–8 $ / month); Proton's static IPs are business-plan only; AirVPN, Mullvad and IVPN offer none — use DDNS against the stable exit IP.

- **AirVPN**: up to 5 remote forwarded ports (≥ 2048) included with any plan, but outbound port 25 is blocked and there is no dedicated IPv4 — the exit IP is shared per server (stable while you stay on the same server, use the included `.airdns.org` DDNS).
- **Private Internet Access**: random port forwarding on select servers; the dedicated IPv4 add-on does not allow custom rDNS. IPv6 is deliberately blocked by the client (leak protection).
- **Proton VPN**: one forwarded port on P2P servers with Plus plans; no consumer dedicated IP (static IPs are business-plan only, with a leased dedicated server); no rDNS customization.
- **Mullvad**: up to 5 randomly assigned ports (TCP/UDP, IPv4 and IPv6), but intentionally no static/dedicated IP — bring your own DDNS. Note: ports cannot be added to accounts with an active auto-recurring subscription.
- **IVPN**: port forwarding was fully removed from the service on 2023-09-30 — not usable for self-hosting inbound connections.
- **Windscribe**: ephemeral port forwarding included with Pro; the Static IP add-on gives a fixed dedicated IPv4 with port forwarding (IPv4 only, no rDNS). IPv6 egress only on some locations.

None of these providers offers customizable reverse DNS, and only PIA and Windscribe sell a fixed dedicated IPv4 on a consumer plan (Proton: business plans only) — so per the definition above they are all only partially suitable for self-hosting mail.
:::
